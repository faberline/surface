# Retired Surface MD3 browser sources

The eight primary snapshot sources and representative native and browser
captures are preserved in the [published Material 3 evidence index](https://github.com/faberline/surface/tree/5204847292f6cf6c50eb39d834324ca5dcfb2a8b/docs/evidence/md3).
The linked evidence pins the base revision, source manifests and replay
steps for each primary tree.

[Download](focused-source-overlays.tar.gz) the supplemental archive and
verify it with [the SHA-256 file](focused-source-overlays.tar.gz.sha256).
Extract the archive and use its README to restore any of the ten
focused browser source snapshots from its primary. All ten reproductions
matched the retired files, executable modes and symlink targets.
[Restoration results](verification.txt)

Generated binaries, redundant test outputs and temporary session files are
outside the source archive.
